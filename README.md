# Milly Moo

Site institucional da agência de gestão de mídias sociais Milly Moo. Página única responsiva, construída em HTML, CSS e JavaScript, sem backend ou dependências de aplicação.

## Desenvolvimento

Sirva a pasta raiz com qualquer servidor estático. Execute `npm run check` para conferir a sintaxe e `npm run build` para gerar `dist/`.

## Publicação

Na Vercel, use o preset **Other**, comando de build `npm run build` e diretório de saída `dist`. Não são necessárias variáveis de ambiente. O site também funciona em hospedagens estáticas, inclusive GitHub Pages.
